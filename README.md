# 🌙 Duco — Personal Duco & Tasbih Counter

**Duco** is a modern Android application designed to help Muslims organize their personal Duco (supplications), recite them consistently, and track the number of times they recite each Duco through a simple and beautiful digital counter.

The application provides a peaceful, minimal, and user-friendly experience with Light Mode and Dark Mode support.

## ✨ Features

- **Personal Duco Management** — Add, edit, and delete your own Duco.
- **Digital Tasbih Counter** — Increase your recitation count with a single tap.
- **Individual Counters** — Track recitations separately for each Duco.
- **Recitation Statistics** — View your recitation count and progress.
- **Custom Targets** — Set a personal recitation goal.
- **Dark Mode** — Enjoy a comfortable dark interface.
- **Light Mode** — Clean and elegant light interface.
- **Offline Support** — Access and manage your Duco without an internet connection.
- **Local Data Storage** — Save Duco and counter progress locally.
- **Smooth Animations** — Enjoy interactive counter animations.
- **Haptic Feedback** — Feel feedback when tapping the counter.
- **Simple Navigation** — Easily navigate between Home and Add Duco.

## 📱 Application Screens

### 🏠 Home Screen
The home screen provides a central dashboard where users can view their selected Duco, monitor their recitation count, and use the main counting button.

### 📿 Duco Counter
A dedicated counting button that allows users to increase their recitation count by one with every tap.

### ➕ Add Duco
Users can create and save their own Duco by entering a title, Duco text, and an optional recitation target.

### 🌙 Dark Mode
A modern dark theme designed to provide a comfortable experience, especially during nighttime use.

### 🗂️ Duco Management
Manage personal Duco by adding, editing, selecting, deleting, and tracking individual recitation counts.
